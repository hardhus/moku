# Phase-end moku_dev smoke check (audit/99-checklist.md §4 step 4).
# Unlocks the dev vault, opens every data-bearing module, locks, quits.
# Needs MOKU_DEV_PASSWORD in the environment. Uses `outline`, not `snap`,
# so personal dev data (feeds, secrets, notes) never lands in the output.

wait "Moku Launcher" 10
keys / text:secrets enter
wait "Secrets" 10
outline secrets

wait "Moku Launcher" 10
keys / text:rss enter
wait "Feeds" 10
outline rss
keys esc
wait "Moku Launcher" 10
keys / text:encrypted enter

outline volumes

outline pomodoro

outline settings

wait "Moku Launcher" 10
keys / text:dashboard enter
wait "Dashboard" 10
outline dashboard
